# Strategy Prototype — web build

Собранный веб-билд (Godot 4.6.3, WebGL2, PWA) серого прототипа стратегии. Исходников здесь нет — только результат экспорта.

- Игра: `index.html`
- Бенчмарк сразу: `index.html?scene=bench&auto=1`
- Миссия сразу: `index.html?scene=mission`

Для установки как приложения на iPhone: открыть в Safari → «Поделиться» → «На экран Домой».
